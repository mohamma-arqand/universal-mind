## نقشهی سهفازی (رتبهبندی اثر÷ریسک)

**فاز ۱ — همین نشست (اجرا شد):**
1. **تفکیک «شکست واقعی» از «رد صادقانهی محیط»** — schema migration: ستون `outcome_class` ('ok' / 'blocked_env')؛ speech-بدون-voice = blocked_env نه failed؛ پیشبین از شکستهای واقعی یاد میگیرد. *(بزرگترین تصحیح آماری تاریخچه: ۱۷۲ ردیف)*
2. **تشخیص زهر در عامل** — goal که ۳+ بار در همان گام متوقف شد → «هدفِ زهرآلود» علامت میخورد؛ tick دیگر نمیچرخد؛ گزارش «ادامه بده» هشدار میدهد. *(پایان retry-loop کور)*
3. **دایرهی واژگان روزمره** — ۱۴ واژه به synonym-map قابلیتهای موجود (چاپ→pdf، ترجمه→webfetch+pdf، جستجو→webfetch، تقویم→data، ...)؛ معیار قبولی: هر واژه واقعاً اجرا شود.

**فاز ۲ — جهش declaration-centric (نشستهای بعد):**
4. مانیفست قابلیت: یک DECLARATION dict → registry/vocab/planner/params/report همه از یک منبع مشتق؛ افزودن قابلیت از ۹ نقطه به ۲ نقطه.
5. کانال خطای نشست: تمام ۷۱ except یک محل بروزرسانی کنند (خطاهای نشست قابل-عدد، قابل-گزارش در داشبورد).

**فاز ۳ — گسترش افقی (بلندمدت):**
6. قابلیتهای جدید از واژههای غایب: EmailSuite (SMTP/MAPI)، TranslateSuite (آفلاین لغتنامه)، CalendarSuite.
7. بازجذب face-ب برای speech: جایگزین SAPI با موتور تاتار/آفلاین فارسی.

**رد شده (با دلیل):** REST API (سطح حمله)، چند-عاملی (تعادل عامل سبک)، مایکروسرویس.
