# فرماننامه — همهی فرمانهای فارسی ذهن جهانی

> این سند از خودِ جدول واژگان روتر (`persian_router._VOCAB`) تولید شده — منبع حقیقت، نه فهرست دستی. هر تغییر در کد، این جدول را هم عوض میکند.

## حالتهای ویژه (mode-verbs — قبل از هر مسیری)

| فرمان | اثر |
|---|---|
| **«بیصدا»** | پلتفرم برای همیشه بیصدا میشود (رکورد ماندگار) |
| **«باز صدا»** | صدا برمیگردد |
| **«توضیح بده»** | فقط برنامهی اجرا را نشان میدهد، اجرا نمیکند |
| **«هدف: …»** | حالت عامل چندگامی با داوری ARETĒ |
| **«ادامه بده»** | اهداف متوقفشده را از سر میگیرد |
| **«دوباره امتحان کن»** | آخرین اجرای ناموفق را با استراتژی دیگر بازمیزند |
| **«واژهی X یعنی Y»** | واژهی جدید یاد میدهد (بدون کدنویسی) |

## سوالات بازتابی (دربارهی خود پلتفرم — از DB واقعی)

| پرسش | پاسخ |
|---|---|
| «چند تا اجرا موفق داشتی؟» | شمارش واقعی از run_history |
| «موفقترین قابلیت کدومه؟» | رتبهبندی واقعی |
| «امروز چی کار کردی؟» | اجراهای امروز |
| «چند روز است زنده؟» | تپش واقعی |
| «امروز چندمه؟» | تاریخ جلالی |
| «ساعت چنده؟» | ساعت + تاریخ |
| «چند وقته دستگاه روشن است؟» | uptime واقعی ویندوز |
| «بکاپ سالم است؟» | آخرین بکاپ + تست یکپارچگی |
| «اسمت چیه؟» / «تو کی هستی؟» / «وضعیتت چطوره؟» / «چه کارهایی بلدی؟» | هویت و خودشناسی |
| «یادآورهای من» | فهرست واقعی یادآورها با زمان بعدی |
| «یادم بنداز که فردا ساعت ۸ …» | یادآور یکبارمصرف (بعد از شلیک خودش حذف میشود) |
| «یادآور «X» را حذف کن» | حذف با تطبیق متن |
| «یادآور کن هر ۳۰ دقیقه …» | زمانبند تکرارشونده |
| «هر روز ساعت ۸ …» | زمانبند روزانه |

## قوانین صداقت (چرا این پلتفرم متفاوت است)

- هیچ عددی جعل نمیشود؛ هر عدد از DB یا اندازهگیری واقعی میآید
- فرمان ناشناخته: «نشناختم» + پیشنهاد — هرگز حدس نمیزند
- سیگنال خواندهنشده نام برده میشود («X خوانده نشد»)، هرگز ساکت نمیماند
- حذف فایل فقط با «تأیید کن»؛ پیشنمایش پیشفرض است
- جستجوی فایل فقط-خواندنی است؛ مرزهای ناقص (زمان/سقف/پوشهی قفل) گزارش میشوند
