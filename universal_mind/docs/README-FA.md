# ذهنِ سراسری — Universal Mind

**دستیارِ شخصیِ فارسی‌زبانِ ویندوز — محلی، صادق، بدون اینترنت.**

یک فایل نصبی استاندارد (`.exe`) — دابل‌کلیک کن؛ نه پایتون لازم است، نه pip، نه اینترنت. پس از نصب، روی دسکتاپ میانبر می‌گذارد و (اختیاری) با هر روشن‌شدنِ ویندوز بالا می‌آید.

---

## کدام نسخه؟

| | **Full — ۸۸MB** | **Lite — ۴۴MB** |
|---|---|---|
| همهٔ قابلیت‌های روزمره (زیر) | ✅ | ✅ |
| بیناییِ کامپیوتر (OpenCV: لبه‌یابی، کانتور، برش تصویر) | ✅ | — ردِ نامدار با راه‌حل |
| پردازشِ سیگنال + یادگیریِ ماشین (scipy/sklearn) | ✅ | — |
| مناسبِ | کاربرِ کامل | دانلودِ سریع، هر پردازنده‌ای |

## چه کاری واقعاً میکند (همهٔ آفلاین)

- 🕐 **ساعت و تاریخِ شمسی** — «ساعت چنده؟»، «تاریخ امروز چند است؟»
- ⏰ **یادآور و قرار** — «یادآور فردا ساعت ۹ ورزش»، «قرار بگذار شنبه ساعت ۱۰ جلسه»، «چند تا یادآور دارم؟»
- 🔊 **صدای واقعی** — «صدا را بلندتر کن»، «ولوم روی ۳۰» — ولومِ واقعیِ ویندوز را تغییر میدهد و قبل/بعد را اندازه‌گیری‌شده گزارش میکند
- 🪟 **پنجره‌ها** — «پنجره‌های باز را نشان بده»، «پنجرهٔ نوپد را ببند»
- 💾 **وضعیت سیستم** — «وضعیت سیستم را بگو» (CPU/RAM/دیسکِ زنده)، «رم را آزاد کن» (فعلِ واقعی + گزارشِ قبل/بعد)
- 📄 **گزارش و سند** — گزارشِ HTML/PDF، نمودار، تبدیلِ فایل (CSV/JSON/اکسل)، زیپ
- 📝 **یادداشت و دفترچه** — ثبت، جست‌وجو، ویرایش
- 🗣️ **گفتار** (اگر TTS ویندوز فعال باشد) — «بگو ساعت چنده»

**قانونِ صداقت**: هر کاری را که نمیتواند واقعاً انجام دهد، صریح میگوید و راهِ انجامش را نشان میدهد — هرگز نتیجه جعل نمیکند. (مثلاً شعرِ خلاقانه بدونِ مدلِ زبانیِ متصل نمیگوید؛ اسکنِ ویروس را به Windows Defender ارجاع میدهد.)

## نصب

1. فایل `UniversalMind-Setup-1.0.0.exe` (یا Lite) را اجرا کن — **Next → Install → Finish**
2. میانبرِ دسکتاپ را دابل‌کلیک کن
3. فارسی بنویس: «سلام» → جواب میگیری

## حذف

Settings → Apps → Universal Mind → Uninstall (تمامِ ردپا پاک میشود).

## برای توسعه‌دهنده‌ها

```bash
git clone <repo> && cd universal-mind
python -m pip install -r requirements.txt
PYTHONPATH=. python -m universal_mind     # درِ مکالمه
python universal_mind/scripts/verify.py   # ۲۶۹۹ تست + ۶۹ پروب
```

ساختِ نصبکننده: `installer/universal_mind_portable.iss` با Inno Setup 6 (ISCC) — یا tag `v*` بزن؛ GitHub Actions خودش میسازد (`.github/workflows/release.yml`).

## گواهِ نهاییِ این نسخه

- ۲۶۹۹ تست سبز / ۰ شکست — ۶۹ پروبِ زنده
- هر دو EXE با نصبِ silent روی همین ماشین گواه شدند: درِ فارسی، ولومِ واقعی، ثبتِ قرار، لیستِ پنجره‌ها — همه از درونِ نصبِ خودشان
- SHA-256 هر دو فایل در `build/installer/SHA256SUMS.txt`
