# R37 — نقشهی ارتقای «چند-لول» دوم (ممیزی زنده، سپتامبر ۲۰۲۶)

> هر پیشنهاد از کد/آزمون زنده کشف شده. رتبه = اثر ÷ ریسک. خط پایه: ۱۳۸۹ تست، ۶۶ probe، verify READY.

## یافتههای ممیزی زنده

### 📊 واقعیت جریانها: فقط ۲۸ از ۱۹۰ زوج جریان دارند (۱۵٪)
**شواهد**: sweep همهی زوجهای ۲۰ قابلیت. ۱۶ زوج پرکاربرد **صفر** جریان:
`database→chart` (ذخیرهها رسم شوند!)، `ocr→database` (متن خواندهشده ذخیره)،
`ocr→pdf` (متن OCR داخل گزارش)، `webfetch→database` (صفحه ذخیره)،
`csv→chart`، `pdfreader→speech` (اسناد بلند خوانده شوند!)، `image→ocr`، `image→vision`...

### 🗣 واقعیت واژگان: ۷ از ۲۳ واژهی روزمره MISS
**شواهد**: `بفرست/ایمیل/چاپ(تکی)/ببین/گوش کن/فیلم/موسیقی/صدا/متن/بنویس/تایپ/بشمار(تکی)`
— «متن بنویس که سلام» و «موسیقی پخش کن» و «این صفحه را ببین» → None.

### 🖥 واقعیت پنجره: ۸ تب، هیچ «گفتار زنده»ای ندارد
پنجره فرمان-محور است؛ هیچ گفتگوی مستمر (چت‌مانند) که اپراتور با آن بنشیند و
حرف بزند وجود ندارد — بزرگترین شکاف UX.

## نقشهی اجرا (۴ لایه، به ترتیب اثر ÷ ریسک)

### 🔴 لایه ۱ — جریانهای دادهی گمشده (۱۶ زوج) — «حافظهی زنده»
| # | جریان | روایت |
|---|---|---|
| A1 | `database→chart` | ذخیرهشدهها رسم شوند — «چی ذخیره کردی را نشانم بده، به‌صورت نمودار» |
| A2 | `ocr→database` | متنِ خوانده‌شده واقعا ذخیره شود — بینایی→حافظه |
| A3 | `webfetch→database` | صفحهی وب ذخیره شود — «صفحه وب رو ذخیره کن» (حالا نصفه است) |
| A4 | `pdfreader→speech` | سند بلند بخواند — کتابخوانِ فارسی |
| A5 | `csv→chart` / `excel→database` / ... | بقیهی زوجها از همین سه الگو |

### 🟠 لایه ۲ — واژگان گفتاری (۱۶ واژه) — «زبانی که اپراتور واقعا حرف میزند»
`بفرست→clipboard/notify، بنویس/تایپ→clipboard، ببین→vision، گوش کن/موسیقی/صدا→speech،
فیلم→media، ایمیل→webfetch(نصب نیست→پرسش صادقانه)، بشمار→data`

### 🟡 لایه ۳ — گفتگوی زنده در پنجره — «نشستن و حرف زدن»
تب نهم «گفتگو»: چت‌مانند، هر خط = route_and_run، تاریخچه در دید،
فرمانهای پیشنهادی زیر آن. اپراتور دیگر «فرمان نمیفرستد»، «گفتگو میکند».

### 🟢 لایه ۴ — حافظهی بلندمدت اپراتور (preferences)
«همیشه نمودار میله‌ای دوست دارم» → ذخیره → دفعات بعد پیش‌فرض می‌شود.
جدول `operator_preferences` + تزریق به params. سیستم شخصی میشود.

## رد‌شدهها (با دلیل)
- **جریان برای هر ۱۹۰ زوج**: بسیاری بی‌معناست (notify→ocr?) — فقط ۱۶ زوج معنادار.
- **ایمیل واقعی (SMTP)**: نیازمند credential/تنظیمات بیرونی — پرسش صادقانه کافی است تا وصل شود.
